This field requires a date and a time (including time zone). The `date_time_reported` value is generated by the sender when the file is created and does NOT reflect a time of any clinical significance. The `date_time_reported` value is strictly metadata correlated with the file sent. This metadata is used to determine the latest record for a document.

**NOTE:** This element MUST contain year, date, month, hours, minutes, seconds and time_zone values. Fractions of seconds (up to nine decimal places) are optional.
